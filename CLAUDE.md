# my_cv

Personal CV website for Tom Amos. Static site: `index.html` + `style.css`.

## Keep `cv.md` in sync with the site

`tom_amos_cv.md` is the downloadable Markdown version of the CV, offered via the
"Download CV" button in the site header. Its content is derived from the CV sections in
`index.html` (Profile, Skills, Experience, Education, Contact).

**Whenever you edit CV content in `index.html`, make the matching change in
`tom_amos_cv.md` in the same commit.** This includes adding/removing/reordering roles, editing bullet points,
job titles, dates, skills, the profile paragraph, or contact links. After editing,
sanity-check that the two files carry the same information.
